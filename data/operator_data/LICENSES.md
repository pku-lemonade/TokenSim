| `v100_sxm2/nccl` | TokenSim legacy `TransformerRoofline/allreduce_v100.xlsx` (repository history) | Project data | nccl-tests all_reduce_perf on a V100 node, fp32, 2/4/8 GPUs. |

Systems that exist upstream but have no data at this commit: `a100_pcie`,
`h100_pcie`, `l4`, `a30` (empty directories). Upstream tables not imported:
`dsv4_megamoe_module` (DeepSeek-V4 fused MoE module with a bespoke schema),
`mla*`, `linear_attention`, `kda`, `mamba2`, `msa`, `mhc`, `sparse_attention`,
`quantize`, `encoder_attention`. See [`../devices/README.md`](../devices/README.md)
for the per-device status.

Regenerate a package with:

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/ai-dynamo/aiconfigurator.git /tmp/aiconfigurator
git -C /tmp/aiconfigurator sparse-checkout set aic-core/src/aiconfigurator_core/systems/data/a100_sxm
python -m TokenSim.operator_data.cli import-aiconfigurator \
  --system-dir /tmp/aiconfigurator/aic-core/src/aiconfigurator_core/systems/data/a100_sxm \
  --device a100_sxm_80g --backend vllm --upstream-commit "$(git -C /tmp/aiconfigurator rev-parse HEAD)"
```

Data measured on our own hardware with `scripts/collect/` carries
`source_id` prefixes `aiconfigurator-collector:` (kernels timed by the
AIConfigurator collector) or `measured:` (TokenSim scripts) and is project data.
